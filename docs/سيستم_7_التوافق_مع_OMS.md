1. المبدأ
نظامك (Zaki AI Response Engine) بيضل مستقل بقاعدة بياناته. الربط مع الـ OMS عبر API وعقد مكتوب بس، بلا ما يلمس أي نظام قاعدة بيانات التاني. الـ OMS **مالك الطلبات بعد التأكيد، والأسعار والعروض**؛ نظامك مالك **المحادثات والمسودات والذكاء**.

3. شو بيسحب نظامك من الـ OMS
**المنتجات:** السعر · العروض · المنتجات المكمّلة · سقف الخصم لكل منتج ودور · سعر الجملة (لأدوار محددة بس)
**الزبون:** هل موجود · طلباته السابقة · قيمته · هل بالقائمة السوداء
**الطلب:** حالته بآلة الحالات · حالة شحنته من شركة التوصيل
**العروض الحيّة:** الكمية المتبقية والمدة — عشان الإلحاح يكون صادق
مزامنة دورية بالطابور الموجود عندك + تحديث عند الحاجة
4. شو بيبعت نظامك للـ OMS
**الطلب بعد التأكيد:** من OrderDraft المكتمل ← طلب بالـ OMS مع لقطة الأسعار ومصدر المحادثة (أي إعلان) ومفتاح عدم تكرار
**نتيجة التأكيد:** مؤكد · لا يرد · مؤجل · ملغي + ملاحظة
**ملاحظات المتابعة المصنّفة**
5. نقاط التكامل (العقد)
الأسماء النهائية بتنضبط وقت البناء؛ هون المبدأ. نقاط الـ OMS بتنبنى بالتوازي لأن الـ OMS نفسه بمرحلة التشطيب.

6. التوكن والصلاحية
توكن بصلاحية **قراءة + إنشاء طلب مؤكد + نتيجة + ملاحظة** بس
ما في صلاحية تغيير حالة ولا سعر ولا صرف
التوكن مشفّر بنفس آلية تشفير أسرار القنوات الموجودة عندك (AES-256-GCM)، وما بيوصل لأي موديل
7. الخصوصية
أرقام وأسماء وعناوين الزبائن بتتقنّع قبل أي موديل خارجي
النموذج الداخلي على سيرفرك بيشوفها كاملة
آلية الحجب الموجودة بالسجلات بتنضاف لها مرحلة تقنيع قبل الاستدعاء الخارجي
